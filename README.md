# Krzyżówka React

Krzyżówka React to prosta aplikacja webowa napisana w bibliotece React służąca do rozwiązywania interaktywnej krzyżówki z pojęciami z dziedziny informatyki.

## Instalacja

Użyj menedżera pakietów npm do zainstalowania zależności.
```bash
npm install
```
## Uruchomienie

Uruchomienie aplikacji w trybie deweloperskim:

```bash
npm run dev
```

## Uruchomienie testow


```bash
npm test
```
